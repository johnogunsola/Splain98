Splain 98 — portfolio source code

GET STARTED
1. Extract this ZIP file.
2. In VS Code, choose File > Open Folder and select Splain98.
3. Open index.html in your web browser to try the desktop.

FILES
index.html: desktop structure and pixel SVG icons.
style.css: Windows 98 appearance and responsive layouts.
app.js: portfolio text, windows, Start menu, settings and saved notes.

No npm install or build step is needed.
Changes here are local; they do not automatically update your hosted site.
Settings and notes are stored locally in the browser when supported.
